# Cooking Masterclass Checkout

## Overview

A Vue 3 shopping cart prototype for cooking courses. Users can browse courses, add them to a cart, adjust quantities, and view live pricing totals.

## Features

- Course catalogue
- Add to cart functionality
- Quantity increase/decrease
- Remove items
- Sold out handling
- Live subtotal, tax, and total calculation

## Tech Stack

- Vue 3
- Vite
- JavaScript

## Run Project

npm install  
npm run dev
