# Homes & Beyond - Property Listings App

## Project Overview

Homes & Beyond is a Vue 3 single-page application that displays property listings in Cape Town.  
Users can browse available properties, search by title or location, and sort listings by price.

The goal of this project is to practice Vue fundamentals including components, props, computed properties, and event handling.

---

## Features

- Dynamic property listings using `v-for`
- Reusable `PropertyCard` component
- Search functionality (filter by title or location)
- Sorting by price (low to high / high to low)
- Conditional display for unavailable properties
- Responsive card-based layout
- Clean and simple UI design

---

## Technologies Used

- Vue 3
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

---
