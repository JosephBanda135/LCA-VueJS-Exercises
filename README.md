# 🍳 Cape Town Food Fest Ticket Landing

## Project Overview

This is a Vue 3 single-page application for the Cape Town Food Fest event.  
It displays different ticket tiers (Bronze, Silver, Gold) with pricing, benefits, and interactive features.

Users can:

- View ticket options
- See featured ticket highlights
- Favourite a ticket tier
- Interact with a responsive UI

---

## Features

- Dynamic ticket rendering using `v-for`
- Reusable Vue component using props
- Featured ticket styling (Gold tier highlight)
- Favourite / like interaction system
- Responsive card layout
- Clean and modern UI design
- Conditional rendering using `v-if`

---

## Technologies Used

- Vue 3
- Vite
- JavaScript
- HTML
- CSS

---

## Installation

```bash

```

## Run Project

