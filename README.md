# FlexZone Fitness Scheduler

## Project Overview

FlexZone Fitness Scheduler is a Vue 3 single-page application that allows gym staff to manage fitness class sessions. Users can add new fitness classes, view scheduled sessions, and delete sessions when they are no longer needed.

This project was built as part of a Vue.js learning exercise focusing on components, props, forms, computed properties, and event handling.

---

## Features

- Display fitness class sessions dynamically
- Add new sessions using a form
- Form validation to prevent empty submissions
- Delete existing sessions
- Dynamic total session count
- Empty state message when no sessions exist
- Responsive card-based layout
- Reusable Vue components

---

## Technologies Used

- Vue 3
- Vite
- JavaScript
- HTML5
- CSS3
